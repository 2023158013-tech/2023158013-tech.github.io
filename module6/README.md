### 📂 상세 기록 바로가기

#### 1. [🎓 프로젝트 회고](/module6/project_review)
* **주제**: 정산·재무 데이터 정합성과 동시성 제어, 성능 최적화 회고
* **핵심 내용**:
  * 은행별 CSV 양식을 **금액·일시 표기 2축**으로 추상화(4유형 대응), 세금계산서 매입/매출 자동 구분
  * 자동이체 오판 사례를 계기로 한 **4단계 중복 검증 확장**(최종 7개 컬럼 조합)
  * 세금계산서·입출금 매칭의 **상황별 동시성 설계** — `FOR UPDATE` 행 잠금 vs 조건부 UPDATE
  * `EXPLAIN` 실측 기반 인덱스·CTE·배치 처리로 filesort·풀스캔·N+1 제거
  * 재무 도메인 JPA 미사용 발견을 계기로 한 "기능 검증과 구조 준수는 다른 확인 지점"이라는 성찰

#### 2. [⚙️ 내가 맡은 기능](/module6/my_role)
* **주요 역할**: 정산·재무·체크리스트·이미지 네 도메인 약 40개 API 개발 + DBA(ERD·Flyway·스키마 설계)
* **핵심 내용**:
  * 입출금/세금계산서 CSV 업로드·중복검증·매칭·필터·단건조회 등 재무 도메인 전반 구현
  * 이미지 CRUD·복구·휴지통·다운로드·모아보기, 체크리스트 CRUD 구현
  * ERD 최신화, Flyway 도입 리서치 및 공유, 초기 DDL 마이그레이션 순서 정리, 템플릿 저장방식(MongoDB vs MySQL+MyBatis+JSON) 검토
